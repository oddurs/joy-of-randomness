- A tangled, self-crossing path that wanders around the origin
- Final distance typically around 30-80 units (varies each run)
- Maximum distance usually 1.3-1.5× the final distance

**Key insight:** The path looks beautiful and complex, but it's generated by a simple rule: step randomly. This is the essence of randomness—simplicity generating apparent complexity.

### Exercise 5.4: Return Probability in 2D

**Solution:**

```python
import numpy as np
import matplotlib.pyplot as plt
from simulations import return_to_origin_2d

# Collect return times
num_walks = 500
max_steps = 100000
returns_2d = []

print("Running 2D walks...")
for i in range(num_walks):
    if i % 100 == 0:
        print(f"  {i}/{num_walks}")
    ret = return_to_origin_2d(max_steps)
    if ret is not None:
        returns_2d.append(ret)

returns_2d = np.array(returns_2d)

# Statistics
percent_returned = 100 * len(returns_2d) / num_walks

print(f"\n2D Return Statistics:")
print(f"  Returned: {len(returns_2d)}/{num_walks} ({percent_returned:.1f}%)")
print(f"  Median return time: {np.median(returns_2d):.0f} steps")
print(f"  Mean return time: {np.mean(returns_2d):.0f} steps")
print(f"  Max return time: {returns_2d.max()} steps")

# Plot
plt.figure(figsize=(10, 6))
plt.hist(returns_2d, bins=50, alpha=0.7, edgecolor='black')
plt.set_xlabel("Steps Until Return")
plt.set_ylabel("Count")
plt.set_title(f"2D Return Times ({len(returns_2d)} returns out of {num_walks})")
plt.xscale('log')
plt.yscale('log')
plt.grid(True, alpha=0.3, which='both')
plt.tight_layout()
plt.show()
```

**What to expect:**
- ~95-98% of 2D walkers return within 100,000 steps
- Median return time around 500-2000 steps
- A long-tailed distribution; some return very quickly (2 steps minimum), others take much longer
- On log-log plot, appears approximately linear (power-law distribution)

**Key insight:** This is Pólya's theorem in action. In 2D, return is nearly certain. The small percentage that don't return within 100,000 steps are statistically unlikely to never return; with more time, almost all would return.

### Exercise 5.5: Return Probability in 3D

```python
# Collect return times

print(f"  Theory (Pólya): ~34%")
print(f"  Median return time: {np.median(returns_3d):.0f} steps")
print(f"  Mean return time: {np.mean(returns_3d):.0f} steps")

axes[0].grid(True, alpha=0.3, which='both')

# Comparison: 2D vs 3D
axes[1].bar(['2D', '3D'], [97, percent_returned], color=['green', 'orange'], alpha=0.7, edgecolor='black')
axes[1].axhline(y=34, color='red', linestyle='--', linewidth=2, label='Theory for 3D (~34%)')
axes[1].set_ylabel("Return Probability (%)")
axes[1].set_title("Return Probability: 2D vs 3D")
axes[1].set_ylim(0, 105)
axes[1].legend()
axes[1].grid(True, alpha=0.3, axis='y')

plt.tight_layout()
plt.show()

print(f"\nComparison:")
print(f"  2D return rate: ~97% (recurrent)")
print(f"  3D return rate: ~{percent_returned:.0f}% (transient)")
print(f"  Difference: This is the recurrence threshold!")
```

**What to expect:**
- ~30-40% of 3D walkers return within 100,000 steps
- This matches Pólya's theoretical prediction of ~34%
- The other ~60% wander off forever (with the remaining time)
- Return time distribution is similar in shape to 2D but reflects lower overall return probability

**Key insight:** Crossing from 2D to 3D crosses a fundamental threshold. In 2D, escape is impossible. In 3D, escape is likely. This threshold is absolute and sharp.

```python
import numpy as np
```

```python
    if d <= 2:
        theory = "~1.00 (recurrent)"
    elif d == 3:
        theory = "~0.34"
    else:
        theory = "→0 (transient)"
    
    print(f"{d:>9} | {rate:>11.2f} | {theory}")

# Plot
fig, ax = plt.subplots(figsize=(10, 6))

recurrent_dims = [d for d in dimensions if d <= 2]
recurrent_rates = [return_rates[i] for i in range(len(dimensions)) if dimensions[i] <= 2]
transient_dims = [d for d in dimensions if d > 2]

ax.plot(recurrent_dims, recurrent_rates, 'o-', color='green', linewidth=2, markersize=10, label='Recurrent')
ax.plot(transient_dims, transient_rates, 's--', color='red', linewidth=2, markersize=8, label='Transient')

ax.axhline(y=1.0, color='green', linestyle=':', alpha=0.3, linewidth=1)
ax.axhline(y=0.34, color='orange', linestyle=':', alpha=0.3, linewidth=1, label='3D theory (~0.34)')
ax.axvline(x=2.5, color='black', linestyle=':', alpha=0.3, linewidth=1)

ax.set_xlabel("Dimension")
ax.set_ylabel("Return Probability")
ax.set_title("Pólya's Recurrence Theorem by Dimension")
ax.set_ylim(-0.05, 1.1)
ax.grid(True, alpha=0.3)
ax.legend(fontsize=11)

plt.tight_layout()
plt.show()
```

**What to expect:**
- d=1, 2: ~1.0 (almost all return)
- d=3: ~0.34
- d=4, 5, 6, 10: decreasing toward 0
- Sharp transition between d=2 and d=3

**Key insight:** The threshold at d=2.5 is one of the most striking divides in probability. Just one dimension difference changes the outcome from "always return" to "usually escape."

### Exercise 5.8: Understanding the Threshold

**Solution:**

```python
import numpy as np
import matplotlib.pyplot as plt
from simulations import return_probability_nd

# Detailed sampling around the critical region
dimensions = [1, 1.5, 2, 2.5, 3, 3.5, 4, 5]
# Note: On a grid, only integer dimensions work. 
# For fractional dimensions, we'd need to think about this theoretically.
# For now, focus on integers around 2-3.

dimensions = [1, 2, 3, 4, 5]  # Stick to integers for grid simulation
return_rates = []
confidence_intervals = []

print("Detailed sampling around recurrence threshold...")

for d in dimensions:
    walks = 300 if d <= 3 else 150
    # Estimate with confidence interval using bootstrap
    samples = []
    for _ in range(10):  # 10 runs
        rate = return_probability_nd(d, num_walks=walks//10, max_steps=30000)
        samples.append(rate)
    
    samples = np.array(samples)
    mean_rate = samples.mean()
    ci_low = np.percentile(samples, 2.5)
    ci_high = np.percentile(samples, 97.5)
    
    return_rates.append(mean_rate)
    confidence_intervals.append((ci_low, ci_high))
    
    print(f"d={d}: {mean_rate:.3f} ± [{ci_low:.3f}, {ci_high:.3f}]")

# Plot with confidence intervals
fig, ax = plt.subplots(figsize=(10, 6))

means = return_rates
errors = [(m - l, h - m) for m, (l, h) in zip(means, confidence_intervals)]
errors = list(zip(*errors))

ax.errorbar(dimensions, means, yerr=errors, fmt='o-', linewidth=2, markersize=10,
           capsize=5, capthick=2, color='blue', label='Observed (with 95% CI)')

# Add theoretical curves
ax.axhline(y=1.0, color='green', linestyle=':', alpha=0.5, linewidth=2, label='Theory: 1.0 (d≤2)')
ax.axhline(y=0.34, color='orange', linestyle=':', alpha=0.5, linewidth=2, label='Theory: 0.34 (d=3)')

# Shade regions
ax.axvspan(0.5, 2.5, alpha=0.1, color='green', label='Recurrent region')
ax.axvspan(2.5, 5.5, alpha=0.1, color='red', label='Transient region')

ax.set_xlabel("Dimension")
ax.set_ylabel("Return Probability")
ax.set_title("Detailed View: The Recurrence Threshold")
ax.set_ylim(-0.1, 1.15)
ax.set_xticks(dimensions)
ax.grid(True, alpha=0.3)
ax.legend(fontsize=10)

plt.tight_layout()
plt.show()
```

**What to expect:**
- Very sharp transition between d=2 and d=3
- Confidence intervals narrow with more sampling
- Clear demarcation: guaranteed return vs likely escape

**Key insight:** This threshold is not gradual or fuzzy—it's sharp. The mathematics predicts exactly this behavior, and empirical simulation confirms it.

## Thought Experiment Solutions

### Exercise 5.10: The Intuition Problem

**Explanation:**

**1D (line):**  
You're confined to a 1D line. You can only go left or right. Every position is on this line. The walker must cross every point infinitely often. Return is inevitable.

**2D (plane):**  
More space than 1D, but still constrained to a 2D plane. The walker explores in many directions. However, the exploration is "thorough" enough that every point is eventually visited. The key: space grows like r (circumference), but the walker's exploration grows faster. Return is still guaranteed, just slower.

**3D (space):**  
Now the walker is in true 3D. Space grows as r² (surface area). The walker's exploration grows as n^(3/2) (because it moves in 3 independent directions). Space grows faster than exploration. The walker can find "pockets" of unexplored space and get lost in them. Escape becomes likely.

**General pattern:**  
The number of nearby lattice points grows as r^(d-1). The walker visits roughly n points. For return:
- d=1: Points ∝ 1, visits ∝ n → walker revisits everything
- d=2: Points ∝ r, visits ∝ n → walker still revisits everything
- d=3: Points ∝ r², visits ∝ n → walker can escape (space grows faster)

**Physical intuition:**  
Imagine you're in a fog with visibility 1 unit. In 1D, you can see the whole line in any direction—you can't get lost. In 2D, you can see a circle around you—you still eventually explore everything. In 3D, you can see a sphere, but there's "more space behind you" than you've explored. You can wander forever without retracing your path.

### Exercise 5.11: Lattice vs Continuous

**Answers:**

1. **Grid vs continuous:** Grid walks are an approximation. Real Brownian motion is continuous and uncountable. However, the core behavior is preserved: recurrence in 1D/2D, transience in 3D+.

2. **Why Pólya applies to continuous motion:** The theorem is about dimensionality and growth of space, not about discreteness. Any random walk model (grid or continuous) satisfies the same properties: recurrent in d≤2, transient in d≥3.

3. **Real Brownian motion:** Pólya's theorem absolutely applies. Pollen grains doing Brownian motion in 2D water (between glass plates) will always return to any region. But in 3D water, they likely escape.

4. **Implication for diffusion:** In 2D (thin membranes, surfaces), particles exploring randomly will "find" any target. In 3D (biological cells, tissue), random exploration is less reliable—you might need directed motion to find specific regions.

### Exercise 5.12: Real-World Dimension

**Analysis:**

1. **Bacterium in water:** True 3D (assuming open space). Expected: transient. The bacterium can wander far; chemotaxis helps it navigate.

2. **Person in a city:** Effectively 2D (constrained to streets and ground level). Expected: recurrent on the street network. But the street network isn't truly random; it has structure.

3. **Molecule in a cell:** Confined 3D (bounded by cell membrane). Expected: effectively 1D or 2D because it's bounded. A random walk in a bounded region is always recurrent.

4. **Air pollution dispersing:** 3D (though atmospheric layers constrain it somewhat). Expected: transient—pollution drifts away.

**Key insight:** Real systems are rarely pure random walks, but when they approximate random walks, the dimension determines whether they return.

### Exercise 5.13: The 3D Bird Problem

**Reflection:**

In 1D (a line), being lost means you'll find your way. The mathematics guarantees return.  
In 2D (a plane), same thing—you'll wander but eventually return.  
In 3D (space), it's different. There's a 2 in 3 chance you wander forever.

This is a profound difference. A drunk person on the ground will always get home (eventually). A drunk bird in the sky might not.

This isn't about intelligence or intention—it's pure geometry. The space is too big relative to random exploration.

**Deeper thought:** This partly explains why animals in 3D environments (like fish in the ocean, birds in the sky) have evolved navigation systems (internal compasses, landmarks, memory), while simpler 2D organisms (like bacteria on surfaces) can rely more on random search. Dimension shapes evolution.

## Key Takeaways

After these exercises, you understand:

1. **Dimension profoundly affects random walk behavior**. The same rules in different dimensions lead to radically different outcomes.

2. **Pólya's recurrence theorem** is not just theory—it's empirically observable and has real physical consequences.

3. **The threshold is sharp and absolute.** There's no gradual transition; dimension 2 is fundamentally different from dimension 3.

4. **The intuition is geometric.** Higher dimensions have "more room," and space can outpace exploration.

5. **Real systems are shaped by dimensionality.** This principle affects diffusion, search, evolution, and physics.

These ideas will reappear throughout probability and physics. They're foundational concepts, not mere curiosities.
