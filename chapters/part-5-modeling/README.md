# Part 5: Modeling

## Randomness in the Real World

Now we use randomness to model actual phenomena. Real systems are messy: they have variability, multiple interacting parts, and outcomes we can't perfectly predict. This is where stochastic modeling shines.

In Part 5, we build probabilistic models of three classical scenarios: disease spreading through a population, customers waiting in queues, and populations growing or dying out. Each chapter shows how randomness captures essential features of real systems that deterministic models would miss.

These are the models that epidemiologists, engineers, and biologists actually use. You'll see how to think like a modeler: build a simple system, run it many times, and extract insights from the distribution of outcomes.
