# Chapter 1: The Pattern-Seeking Mind

## Metadata
- **Part**: 1 - Intuition
- **Topics**: Pattern recognition, cognitive biases, randomness perception
- **Key Concepts**: Apophenia, selective attention, null hypothesis intuition

## Overview
Humans are pattern-seeking creatures. We find patterns everywhere—sometimes even where they don't exist. This chapter explores how our minds fool us about randomness.
